# 🧹 Plenora — Home Cleaning & On-Demand Services Mobile App

**Plenora** is a state-of-the-art Flutter mobile application designed to deliver an effortless, premium experience for booking home cleaning, electrical, painting, and appliance repair services.

> **🚧 Project Status: Demo / Ongoing Development**
> Plenora is currently a **demo/prototype project and is still under active development**. Some features, functionality, and integrations are incomplete and may change as development continues. This version is intended to demonstrate the current UI, UX, and core application flow.

## ✨ Features

* 🔑 **Persistent Authentication**: Seamless login and signup session persistence powered by `shared_preferences`.
* 🔍 **Real-Time Interactive Search**: Dynamic search filtering services across titles, descriptions, and category tags.
* 🎨 **Modern & Premium UI Design**: Deep emerald glassy gradients, fluid micro-interactions, responsive floating bottom navigation, and custom Nunito typography.
* 🔔 **Interactive Notification Center**: Notification panel with read/unread state persistence and badge indicators.
* 📱 **Responsive Layouts**: Designed to adapt across different mobile screen sizes.
* 📅 **Service Booking Sheet**: Interactive date and time slot selection with booking confirmation flow.

## 🛠️ Built With

* **Framework**: Flutter (Dart)
* **State Management**: Stateful Widgets & Dynamic Callbacks
* **Persistence**: `shared_preferences`
* **Typography**: `google_fonts` (Nunito)
* **Icons**: Material Icons & Custom Asset Vector Art

### 🚧 Development Status

**Plenora is not yet a completed production application.**
It is currently being developed and refined, with additional features, backend integrations, testing, and improvements planned for future versions.
